# Portafolio Personal

## Nombre

Rony Israel Cando Jacome

## Descripcion

Este proyecto consiste en el desarrollo de un portafolio personal utilizando HTML y CSS.

El sitio web presenta información sobre mi perfil, habilidades y algunos proyectos desarrollados durante mi experiencia y formación en el área de tecnología.

El portafolio contiene las secciones Inicio, Sobre mí, Habilidades, Proyectos y Contacto.

## Tecnologías utilizadas

- HTML5, CSS3, Git, GitHub

## Características

- Diseño de portafolio personal.
- Menú de navegación.
- Sección principal de presentación.
- Sección Sobre mí.
- Sección de habilidades.
- Sección de proyectos.
- Formulario visual de contacto.
- Diseño adaptable para computadoras, tablets y dispositivos móviles.
- Efectos mediante la pseudoclase `:hover`.

## Proyectos presentados

En el portafolio se presentan los siguientes proyectos:

- Sistema ERP.
- Sistema de Facturación Electrónica.
- Sistema de Encomiendas.
- Sistema de Reservas de Boletos.

Los sistemas presentados son privados, por lo que no disponen de enlaces públicos.

## Cómo visualizar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador web.

También puede visualizarse mediante GitHub Pages una vez publicado.
